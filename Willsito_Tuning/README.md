# WillsitoGG tuning

This directory contains only the current metadata needed to identify the WillsitoGG Direct Forwarder Fix v2.

The functional fix is integrated directly into `main` at `switch_launcher/source/main.cpp`. The separate `fix/direct-forwarder` branch is retained while upstream PR NaGaa95/Cemu-nx#5 remains open.

The current installable `Cemu.nro` is published in this fork's GitHub Releases. Release identification and the current NRO SHA-256 are recorded in `RELEASE_STATUS.md`.
