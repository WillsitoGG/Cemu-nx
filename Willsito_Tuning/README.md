# WillsitoGG tuning

This directory contains only the current tuning metadata and minimal validation for the WillsitoGG Direct Forwarder Fix v2.

The functional fix is integrated directly into `main` at `switch_launcher/source/main.cpp`. The separate `fix/direct-forwarder` branch is retained only while upstream PR NaGaa95/Cemu-nx#5 remains open.

The current installable `Cemu.nro` is published in this fork's GitHub Releases.
